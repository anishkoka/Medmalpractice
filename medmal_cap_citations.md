# Medical Malpractice Damage Cap Citations — All 51 Jurisdictions

**Last verified:** April 2026 (April 6, 2026 Tavrn aggregator update, cross-checked against state codes and AMA State Laws Chart I)

## Methodology

For each state, the primary citation is the operative statute or court ruling that controls the current cap status. Where Tavrn (an aggregator with statutory citations) was consulted as the baseline, all values were cross-checked against (a) the actual state code via Justia, FindLaw, or the official legislature site, and (b) the AMA "State Laws Chart I: Liability Reforms" maintained by the AMA Advocacy Resource Center.

**One Tavrn error identified and corrected:** Tavrn lists Tennessee's cap as $1.5M / $2M catastrophic. The actual Tennessee Code § 29-39-102 sets the cap at $750K standard / $1M catastrophic, confirmed by the Tennessee Supreme Court (*Yebuah v. Center for Urological Treatment*, 2021) and multiple corroborating sources.

## Cap-Score Bucket Key

- **0** = Strong cap (≤$500K noneconomic) OR PCF state limiting physician personal exposure
- **10** = Moderate cap ($500K–$1M noneconomic)
- **20** = Weak/partial cap (>$1M total, OR cap only on subset)
- **30** = No cap (struck unconstitutional or never enacted)
- **35** = Constitutional bar to enacting caps
